# Deuce Card Room

Blackjack, Texas Hold'em and Craps in one installable web app, dressed in burgundy and steel blue.

**Play:** https://cody-ayers.github.io/deuce-card-room/

## What's inside
- **Blackjack** with a basic-strategy coach, Perfect Pairs side bet, splits and doubles
- **Texas Hold'em** against three regulars (Rosa, Dutch and Mei) who talk at the table and remember you
- **Craps** with a guided Learn mode and a real-bets Play mode
- **Lounge**: VIP levels with unlockable felts, card backs and stakes, daily chips, achievements, records, a prize wheel, scratch cards and a daily Hold'em puzzle

## Install on your phone
- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** menu → Install app

It works offline after the first visit. Progress is saved on each device.

## Files
| File | What it does |
| --- | --- |
| `index.html` | The whole game: markup, styles and logic |
| `manifest.webmanifest` | App name, colors and icons for installing |
| `sw.js` | Service worker for offline play |
| `icons/` | App icon in every size, plus the source SVG |
